Калькулятор калорий для нормализации веса взрослого мужчины

Расчёт суточной калорийности, белков, жиров, углеводов, примерного меню, витаминов, минералов и осторожных рекомендаций по добавкам.

Важно: калькулятор предназначен только для взрослых мужчин. Он не ставит диагнозы, не лечит ожирение, дефициты, диабет, болезни ЖКТ, почек, печени или сердца. БАДы и витамины нельзя принимать вслепую: корректный путь — питание, анализы, врачебная оценка.

1. Данные мужчины

На основании этих данных рассчитывается базовый обмен, индекс массы тела и целевой калораж.

2. Настройка рациона

Выберите стиль питания. Меню будет собрано из продуктов встроенной базы.

3. Добавить свой продукт

Если продукта нет в базе, добавьте его вручную. Значения указываются на 100 г продукта.

4. База продуктов

Это не вся мировая база продуктов, а встроенный справочник. Его можно расширять.
