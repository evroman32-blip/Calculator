# Вайб-калькуляторы

Набор бесплатных офлайн-калькуляторов на чистом HTML, CSS и JavaScript. Работают в браузере без сервера, установки и регистрации.

## Что внутри

| Инструмент | Описание | Путь |
|------------|----------|------|
| **Калькулятор калорий** | BMR, суточная норма, БЖУ, меню, витамины для взрослого мужчины | `apps/calorie-calculator/` |
| **Семейный бюджет** | Доходы, расходы, накопления, финансовые цели | `apps/family-budget/` |

Главная страница-лендинг: `index.html`

## Быстрый старт

### Вариант 1 — просто открыть файл

Дважды кликните `index.html` в проводнике Windows или откройте его в браузере.

### Вариант 2 — локальный сервер (рекомендуется)

```bash
# Python 3
python -m http.server 8080

# или Node.js (npx)
npx serve .
```

Откройте в браузере: [http://localhost:8080](http://localhost:8080)

## Возможности

- Расчёты в реальном времени
- Сохранение данных в `localStorage` браузера
- Экспорт отчётов в JSON
- Светлая и тёмная тема (общая для всего сайта)
- Адаптивная вёрстка для мобильных устройств

## Деплой на GitHub Pages

1. Создайте репозиторий на GitHub и загрузите проект.
2. В настройках репозитория: **Settings → Pages → Source: Deploy from branch**.
3. Выберите ветку `main`, папку `/ (root)`.
4. Сайт будет доступен по адресу `https://<username>.github.io/<repo>/`.

## Важно

Калькуляторы носят **информационный характер**:

- Калькулятор калорий не заменяет врача, диетолога и лабораторные анализы.
- Калькулятор бюджета не является финансовой консультацией.
